## 🌐 Executive Overview

**CSx-Pedia** is an enterprise-grade cybersecurity intelligence portal, vulnerability disclosure matrix, and advanced software engineering showcase. Designed for high-threat operational environments and elite research teams, CSx-Pedia merges a **photorealistic 3D Quantum WebGL viewport** with a **Quad-Protocol API Backend** (REST, GraphQL, gRPC-Web, SOAP 1.2) connected to serverless edge databases and cloud-proof email pipelines.

### 🎯 Mission & Core Capabilities
* **Zero-Trust Identity Matrix:** Users authenticate via generated 10-character secret ciphers, removing legacy credential theft vectors.
* **Cyber Defense Command Portal:** High-privilege administrative dashboard equipped with one-click **Platform Lockdown**, real-time **IP Threat Filtering**, **Database Connection Quarantine**, and live **Cyber Telemetry Tracking**.
* **Quad-Protocol Hybrid Routing:** Automatically assigns incoming workloads to the most performant protocol: GraphQL for deep content graphs, gRPC-Web for microsecond metrics, SOAP for immutable XML cryptographic tokens, and REST for standard operations.
* **Cloud Datacenter Port-Block Immunity:** Fully decoupled from flaky SMTP ports (25/465/587) using pure HTTPS Port 443 REST relays (Google Apps Script, Brevo, and Resend).
* **Dual Glassmorphic Aesthetic:** Immersive Cyberpunk Matrix dark mode and high-contrast tactical light mode with GPU-accelerated motion blur, Bloom shaders, and momentum physics.

## ⚡ Quad-Protocol API Fusion Engine

CSx-Pedia avoids the "one-size-fits-all" API anti-pattern. The platform employs a **Quad-Protocol Architecture**, dedicating each protocol to the technical domain where it delivers peak performance, security, and developer ergonomics:

| Protocol | Mount Point | Payload Format | Target Domain | Why It Was Chosen |
| :--- | :--- | :--- | :--- | :--- |
| **GraphQL** | `/api/graphql` | JSON / AST | Knowledge Base & Articles | Eliminates over-fetching; allows client to request nested posts, tags, categories, and releases in a single network round-trip. |
| **gRPC-Web** | `/api/grpc` | Protobuf / Simulated RPC | Real-Time Telemetry & Comm-Links | Microsecond payload parsing, binary serialization simulation, sub-30ms transmission of operator metrics and contact payloads. |
| **SOAP 1.2** | `/api/soap` | XML Envelopes | Cryptographic Token Verification | Immutable XML signatures, enterprise compliance verification, strict envelope schemas preventing token tampering. |
| **REST** | `/api/*` | Standard JSON | CRUD, Auth, Admin & File Streams | Universal compatibility, standard HTTP verbs, stream-piped binary PDF generation, and multipart file uploads. |

## 🛡️ Cyber Defense & Emergency Security Command

The Administrative Matrix (`/auth/admin` & `/admin/security`) includes high-impact, state-level cyber operational capabilities engineered to mitigate active breaches, DDOS floods, and credential scraping in real time:

```mermaid
stateDiagram-v2

    OperationalState --> LockdownActive: Admin Triggers Emergency Lockdown
    state LockdownActive {

    }

    OperationalState --> DBQuarantine: Admin Triggers Database Hold

        [*] --> FreezeWritePools

    }

    OperationalState --> IPBlacklisted: Malicious Activity Detected
    IPBlacklisted --> OperationalState: Admin Removes from Blacklist
```

### 1. 🚨 Emergency System Lockdown (`LOCKDOWN MODE`)
* **Instant Platform Cutoff:** One click completely locks down the entire platform.
* **Session Severing:** All active guest sessions and standard user JWT tokens are severed immediately.
* **Admin-Only Bastion:** Only authenticated administrators with verified hardware IPs can access the site. Standard users and guests are presented with an interactive military-grade DEFCON-1 lockout HUD.

### 2. 🌐 Real-Time IP Threat Filtering & Visited IP Tracker
* **Automatic IP Audit:** Every IP address that hits the platform (guest, registered user, or admin) is dynamically tracked with timestamps, request frequency, geolocation markers, and user-agent fingerprints.
* **Dynamic Whitelisting & Blacklisting:** Instantly ban malicious IP ranges or lock down access strictly to a whitelist of trusted CIDR blocks.
* **Admin Absolute Immunity:** The active runtime IP address of the Master Admin is dynamically resolved and **strictly exempted** from any lockouts, ban rules, or rate limits to guarantee the administrator can never be locked out.

### 3. 💾 Database Connection Quarantine (DB Hold Protocol)
* **Write Pool Freezing:** During an active SQL injection or zero-day database exploit, the admin can quarantine and hold the database connection pool.
* **Zero-Lockout In-Memory State Machine:** If the database is frozen, the master admin authentication automatically pivots to a zero-connection cryptographic in-memory state (`MASTER_ADMIN_CREDENTIALS`). The admin retains complete operational control to inspect logs, manage firewall rules, and safely re-establish database connectivity.

### 4. 📲 Sub-20ms Discord Mobile Push Notifications
* High-priority telemetry events (new member registration, contact comm-link intercepts, and critical vulnerability feedback) are pushed to the administrator's mobile device via Discord Webhooks in under **20 milliseconds**, including formatted embeds, operator data, and priority flags.

## 📬 Next-Gen Cloud Mailing Architecture (Port 443 HTTPS)

> [!IMPORTANT]
> **Why SMTP is Obsolete on Cloud Containers:**
> Render, AWS, Azure, and DigitalOcean intentionally block traditional outbound SMTP ports (**25, 465, and 587**) on containerized hosting tiers to prevent spam, resulting in `connect ENETUNREACH` socket failures. 

CSx-Pedia completely removes legacy `nodemailer` and direct TCP sockets, migrating 100% of outbound communications to a **Unified Multi-Engine HTTPS Dispatcher** running on standard **Port 443** (never blocked):

```mermaid
flowchart LR
    Event["User Action <br/> (Registration / Verification / Comm-Link)"] --> Engine["Unified Cloud Dispatcher <br/> backend/src/utils/sendEmail.ts"]
    
    Engine -->|"Priority 1: EMAIL_RELAY_URL"| GAS["Google Apps Script Webhook Relay <br/> (Port 443 HTTPS -> Gmail Native Dispatch)"]
    Engine -->|"Priority 2: BREVO_API_KEY"| Brevo["Brevo REST API <br/> (Port 443 HTTPS -> 300 Emails/Day Free)"]
    Engine -->|"Priority 3: RESEND_API_KEY"| Resend["Resend HTTPS REST API <br/> (Port 443 HTTPS -> Custom Domain)"]

    GAS -->|"Delivers Directly To"| Inbox["Recipient Personal Inbox <br/> (user@gmail.com, user@outlook.com, etc.)"]
    Brevo -->|"Delivers Directly To"| Inbox
    Resend -->|"Delivers Directly To"| Inbox
```

### 1. Google Apps Script Webhook Relay *(Active & Verified)*
* **How it works:** Render makes an HTTPS POST (Port 443) with the email payload to your deployed Google Apps Script Web App. Google's internal datacenter executes `MailApp.sendEmail()`, dispatching the email directly from your Gmail account (`nimnakgls980@gmail.com`).
* **Zero Domain Required:** Works 100% free without buying or configuring any custom domain DNS records.
* **100% Deliverability:** Bypasses spam filters because it originates directly from Google's authenticated mail servers.
* **Delivers to Any Recipient:** Every user who signs up receives their verification code and link in their own personal inbox!

### 2. Brevo (Sendinblue) REST API *(Secondary Engine)*
* Sends up to **300 free emails per day** to any inbox in the world using **Single Sender Verification** (no domain DNS records needed).

### 3. Dynamic Production URL Interceptor
* [`backend/src/config/env.ts`](file:///C:/Users/SANDANIMNE/Desktop/MyCodes/Projs/nima-platform/backend/src/config/env.ts) dynamically extracts `req.get('origin')` from incoming browser headers and implements an active production safeguard: **even if `FRONTEND_URL` is mistakenly configured as `localhost` on Render, the backend automatically intercepts and forces `https://csx-pedia.vercel.app`**. Verification links are permanently immune to localhost errors!

## 🔒 Security, Hardening & Compliance

* **Ephemeral JWT Identity Model:** Access tokens expire after 7 days; email verification tokens carry an explicit `purpose: "verify"` claim and are mathematically blocked from being used as login session tokens.
* **Database Connection Quarantine State:** If the database pool is frozen, the system gracefully pivots to an in-memory hardened admin authentication model so administrative oversight is never lost.
* **XSS & Injection Neutralization:** All dynamic user strings in emails, PDFs, and HTML renderers pass through [`escapeHtml()`](file:///C:/Users/SANDANIMNE/Desktop/MyCodes/Projs/nima-platform/backend/src/utils/escapeHtml.ts) sanitization.
* **Strict CORS Whitelisting:** Browsers can only invoke the API from authorized origins (`https://csx-pedia.vercel.app`, preview domains matching `*.vercel.app`, and `http://localhost:3000`).
* **Hardware Mobile Severance:** Protects the heavy WebGL / Three.js shaders and viewport layout from unoptimized mobile devices.
