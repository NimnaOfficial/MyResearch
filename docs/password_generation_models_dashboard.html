Probabilistic Context-Free Grammars & The "Deadbeat Dad" Queue

PCFGs parse training corpora into pre-terminal structural templates (e.g., L8D3S1) and constituent character strings. While mathematically elegant, naive priority queue implementations push all combinations simultaneously, causing explosive memory growth O(N × M) that triggers Out-Of-Memory (OOM) faults. Matt Weir's "Deadbeat Dad" algorithm defers child node instantiation, inserting only adjacent candidates along a single dimension to maintain linear queue growth O(N + M).

PCFGEngine: Deadbeat Dad Traversal Logic Python Paradigm 
def generate_next(self):
    if not self.pqueue:
        return None
    
    # Pop highest probability state (min-heap with inverted prob)
    neg_prob, s_idx, a_idx, d_idx = heapq.heappop(self.pqueue)
    guess = f"{self.alpha[a_idx]}{self.digit[d_idx]}"
    
    # Deadbeat Dad: Branch ONLY strictly adjacent neighbor states
    neighbors = [
        (s_idx + 1, a_idx, d_idx),
        (s_idx, a_idx + 1, d_idx),
        (s_idx, a_idx, d_idx + 1)
    ]
    for ns, na, nd in neighbors:
        if (ns, na, nd) not in self.visited:
            self.visited.add((ns, na, nd))
            new_prob = (self.structs[ns][0] * 
                        self.alpha[na][0] * 
                        self.digit[nd][0])
            heapq.heappush(self.pqueue, (-new_prob, ns, na, nd))
            
    return guess
Structural Limitation: PCFGs deliver 28% to 129% higher crack yields over legacy JtR rule sets, but cannot produce candidates outside observed grammatical templates.

OMEN: Logarithmic Level Discretization & Markov Trees

The Ordered Markov ENumerator (OMEN) computes candidate probabilities using four transition matrices: IP (Initial Probabilities), CP (Conditional Probabilities), EP (End Probabilities), and LN (Length Probabilities). To eliminate floating-point multiplication underflow and CPU latency, OMEN transforms probabilities into additive integer levels: level(p) = round( -&ln;(p) / λ ).
